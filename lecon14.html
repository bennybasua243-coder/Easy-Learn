XIV. Les Opérateurs arithmétiques

Explication :

Les opérateurs arithmétiques permettent de faire des calculs en Python, comme une calculatrice. Voici les principaux :

• + → addition
• - → soustraction
• * → multiplication
• / → division (donne toujours un float)
• // → division entière (donne un int, sans le reste)
• % → modulo (donne le reste d'une division)
• ** → puissance
