XIX. La Boucle for

Explication :

Une boucle permet de répéter un bloc de code plusieurs fois, sans avoir à le réécrire. La boucle for sert à parcourir chaque élément d'une liste, ou à répéter une action un nombre précis de fois.

Avec range(n) , Python génère automatiquement une suite de nombres de 0 à n-1 .

for fruit in fruits veut dire : "pour chaque élément de la liste fruits, donne-lui le nom fruit, et exécute le code en dessous".
