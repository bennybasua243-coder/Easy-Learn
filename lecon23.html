XXIII. La fonction input() — Saisie de texte

Explication :

Jusqu'ici, les valeurs de tes variables étaient écrites directement dans le code. Avec input() , c'est L'UTILISATEUR qui tape lui-même une valeur pendant l'exécution du programme.

input() affiche un message à l'écran et attend que l'utilisateur tape quelque chose puis appuie sur Entrée.

Exemple :

Pour le moment, cette plateforme ne prend pas en charge les programmes utilisant input(). Cela signifie qu’il n’est pas encore possible de saisir des informations au clavier pendant l’exécution d’un programme Python.

Quand Python exécute input("Entre ton prénom : "), il affiche ce texte et attend. Tout ce que l'utilisateur tape est stocké dans la variable prenom.
